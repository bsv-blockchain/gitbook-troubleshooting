# BSV Troubleshooting Guide

Welcome to the BSV Troubleshooting Guide. This repository contains solutions to common issues encountered when working with BSV Desktop, wallets, and development tools.

## Common Problems

### Wallet & Desktop Issues

#### BSV Desktop Wallet Creation Failures
**Problem:** WAB wallet creation fails or gets stuck during setup

**Quick Solutions:**
- Restart BSV Desktop and retry
- Try a different phone number for verification codes
- Skip advanced configuration (don't manually enter URLs)
- Consider creating a mnemonic wallet instead

[View detailed solutions →](problems/wallet-creation-issues.md)

---

#### iOS Version Compatibility
**Problem:** BSV Desktop doesn't work on certain macOS versions (e.g., Ventura)

**Quick Solution:**
- Use a different device/OS if possible
- Download older BSV Desktop versions from getmetanet.com (not recommended)

[View detailed solutions →](problems/ios-compatibility.md)

---

### Development Issues

#### Transactions Not Being Mined
**Problem:** Transactions remain unconfirmed and don't get mined

**Quick Solution:**
- Update TypeScript SDK to the latest version for current fee rates

[View detailed solutions →](problems/transactions-not-mined.md)
